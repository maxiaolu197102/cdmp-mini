# Kafka 分区清空工具

这是一个用于清空 Kafka 集群中所有主题分区数据的 Shell 脚本工具。

## 功能特点

- 🔍 **自动发现**：自动连接并列出 Kafka 集群中的所有主题
- 🎯 **灵活选择**：支持清空所有主题或指定单个主题
- ⚠️ **安全保障**：执行前提供二次确认机制，防止误操作
- 📊 **进度显示**：实时显示清空进度和结果统计
- 🎨 **友好界面**：彩色输出，清晰的操作提示

## 环境要求

- 需要安装 Kafka 命令行工具（kafka-topics.sh, kafka-consumer-groups.sh）
- 确保 Kafka 命令已添加到系统 PATH 中
- 确保能够连接到目标 Kafka 集群

## 使用方法

1. 确保脚本具有执行权限：

```bash
chmod +x kafka_cleaner.sh
```

2. 运行脚本：

```bash
./kafka_cleaner.sh
```

3. 按照提示进行操作：
   - 查看所有主题列表
   - 选择清空所有主题或指定单个主题
   - 确认操作

## 脚本原理

该脚本使用 Kafka 自带的 `kafka-consumer-groups.sh` 工具，通过创建临时消费者组并将偏移量设置到最新位置的方式来"清空"分区数据。这种方法不会真正删除数据，而是将消费者的读取位置移到最新，适用于测试环境或需要重置数据的场景。

## 注意事项

- ⚠️ **请谨慎使用**：清空操作无法撤销，请确保您了解操作的后果
- 该脚本不会真正删除数据，而是将消费者偏移量设置到最新位置
- 对于生产环境，请先在测试环境验证脚本功能
- 确保您有足够的权限执行 Kafka 命令

## 自定义配置

如需修改 Kafka 集群地址，请编辑脚本开头的 `KAFKA_BROKERS` 数组：

```bash
KAFKA_BROKERS=("192.168.10.8:9092" "192.168.10.8:9093" "192.168.10.8:9094")
```
